# Charte Graphique et Design

Spécifications du restaurant **Recette d'Afrique** :
- **Palette stricte (Règle 60-30-10)** :
  - `blanc` : `#FFFFFF` (60 % de l'interface)
  - `noir` : `#111111` (30 % de l'interface)
  - `rouge` : `#D62828` (10 % : boutons d'action, prix, badges)
  - `gris-clair` : `#F7F7F7` (fonds secondaires / cartes)
- **Typographie et lisibilité** : optimisé pour le mobile dès 360px de largeur.
- **Aucune couleur en dur** dans les composants : utiliser exclusivement les classes Tailwind (`bg-rouge`, `text-rouge`, `bg-noir`, `text-blanc`, etc.).
