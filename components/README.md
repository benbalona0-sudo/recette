# Composants Réutilisables

Ce dossier accueillera les composants UI légers, modulaires et conformes aux règles du projet :
- Mobile-first (écran de référence : 360px).
- Respect strict de la palette 60-30-10 (`blanc`, `gris-clair`, `noir`, `rouge`).
- Aucun code couleur en dur.
- Aucun composant de page ici (uniquement des blocs modulaires et réutilisables).
